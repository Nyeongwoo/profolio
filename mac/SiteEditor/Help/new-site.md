# Making a new site

File ▸ New Site… makes a new portfolio from Profolio's starter, with its own GitHub repository.

1. Sign in to GitHub first (see github-account).
2. Pick a **Layout**: Grid, Showcase, Feed or Compact. You can change all of it later in the inspector.
3. Fill in **Site name**, **Your name** (shown on the site) and **Repository** (letters, numbers, - and _).
4. Keep **Private repository** on unless you want the code public.
5. **Saved in** is where the project file goes (iCloud Drive/Portfolio by default, so it syncs to your other Macs).
6. Create Site. Profolio makes the repository, uploads the starter and opens the project.
7. Put it online: click Connect to Vercel… and import the repository with the defaults (Vercel detects Vite). After that, Publish in Profolio updates the site.

Related: vercel, publishing.

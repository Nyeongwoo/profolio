# Backups

Profolio keeps snapshots of your pages as you edit, inside the project file (so they sync with it through iCloud).

- File ▸ Backups… (⇧⌘B) lists them by page and time. Pick one to see it and restore it.
- Restoring changes the page on this Mac; publish to put it online.
- Replaced and removed images go to the Mac's Trash, so you can get them back from there.

# Publishing

Publish (⇧⌘P, or the toolbar's Publish button) sends your changes to GitHub; Vercel then deploys the site.

- The sheet lists every change with what it does: text before → after, images side by side. Untick changes you want to hold back.
- Add a note if you like; it becomes the commit message.
- Profolio first brings in anything that changed on GitHub (for example from another Mac). If the same value changed in both places, it asks which to keep.
- The toolbar shows "N unpublished changes", or "Published" when everything is online.
- View ▸ Open on Live Site (⌥⌘L) opens the current page on the published site.
- The Lab's pieces can be published on their own with Publish Lab in the sidebar.

Related: vercel, lab.

# GitHub account

Profolio publishes your site to a GitHub repository, so you need a GitHub account and to sign in to it in Profolio.

## Create a GitHub account (if you don't have one)
1. Go to https://github.com/signup.
2. Enter your email, a password and a username. The username becomes part of addresses like github.com/<username>, so pick something short you're happy to show.
3. Confirm the email GitHub sends you.
4. The free plan is enough for Profolio, private repositories included.

## Sign in from Profolio
1. Choose Profolio ▸ GitHub Account….
2. Click Sign In. Profolio shows a short code and opens github.com/login/device.
3. Paste or type the code on that page, then Authorize. Profolio asks for access to your repositories ("repo"), which it needs to publish.
4. The window then shows your username. The sign-in is kept in the Mac's keychain.

If your organisation blocks app sign-ins, the same window offers a personal access token instead (github.com/settings/personal-access-tokens/new, with read and write access to the site's repository).

## Problems
- **Publish says to sign in**: open Profolio ▸ GitHub Account… and sign in again (the sign-in can be revoked on GitHub).
- **macOS asks about the keychain**: allow it, so Profolio can read the saved sign-in.
